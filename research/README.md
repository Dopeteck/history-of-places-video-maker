# Evidence packets

Add a JSON list of `{id, title, url, excerpt}` records you have actually checked. Use IDs such as `source_1`. Sources are not fetched automatically. Relevant excerpts are limited to 6,000 characters each and 24,000 total. Pass the path (for example `research/my-topic.json`) in the workflow's `sources` input, or use `sources_file` in a topic queue entry. Do not commit API keys or private credentials here.
